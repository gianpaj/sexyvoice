Retrieve your current credit balance and latest billing transaction.

## What it returns

- `creditsLeft`: Current available credits, or `0` if there is no balance record.
- `lastUpdated`: Last balance update timestamp, or `null` if unavailable.
- `userId`: User ID linked to your API key.
- `lastBillingTransaction`: Most recent `purchase` or `topup` transaction, or
  `null` if none exists yet. Credit additions still use the value `topup`
  in the API. `reference_id`, `subscription_id`, and `metadata` can be `null`.

## Example Request

```bash
curl -X GET 'https://sexyvoice.ai/api/v1/billing' \
  -H "Authorization: Bearer ${SEXYVOICE_API_KEY}"
```
