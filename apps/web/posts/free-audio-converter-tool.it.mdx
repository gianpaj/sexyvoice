## Perché la Conversione nel Browser Conta

Quando carichi un file su un convertitore online, un server di terze parti lo gestisce. Le tue registrazioni — interviste, bozze musicali, memo vocali — finiscono su hardware che non controlli, processate da codice che non puoi ispezionare.

Questo strumento esegue [FFmpeg](https://ffmpeg.org) direttamente nel tuo browser tramite WebAssembly. La conversione avviene sulla tua macchina. Una volta caricato, funziona anche senza connessione a internet. I tuoi file restano privati.

## Come Funziona

Tre passaggi:

1. **Trascina il file.** Trascina un file audio nel tool o clicca per selezionarlo.
2. **Scegli un formato.** Seleziona MP3, WAV, AAC, OGG, FLAC, M4A o MP4 dal menu.
3. **Converti e scarica.** Guarda la barra di avanzamento, poi salva il file con un clic.

Nessun account richiesto.

Il tool mostra l’avanzamento in tempo reale. Quando finisce, scaricalo subito.

## Formati Supportati

Formati supportati:

- **MP3** — riproduzione universale, file leggeri
- **WAV** — non compresso, qualità lossless
- **AAC** — compressione efficiente, nativo su dispositivi Apple
- **OGG** — formato open, comune in giochi e audio web
- **FLAC** — compressione lossless, preferita dagli audiofili
- **M4A** — contenitore Apple per audio AAC
- **MP4** — contenitore video che include tracce audio

Converti in qualsiasi direzione. WAV in MP3, FLAC in AAC, OGG in WAV — tutte le combinazioni funzionano.
